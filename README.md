## ⚙️ System Requirements (macOS)

* **Operating System:** One of the **three most recent** macOS versions
* **CPU:** Dual-core or better (Apple Silicon or Intel)
* **RAM:** **4 GB** minimum
* **Disk:** **~1.5–3 GB** free
* **Display:** **1200 × 800** or higher
* **Network:** Internet required for sign-in, calls, and meetings

> Note: Microsoft ended availability of **Classic Teams**. If you’re on very old macOS versions, upgrade macOS to use the new Teams client.

## 💡 Tips & Tricks

* **Sign in options:** Work/School (Microsoft Entra ID) or Personal Microsoft Account
* **Notifications:** System Settings → Notifications → Microsoft Teams → Allow
* **Performance:** Close unused apps; prefer wired or strong Wi-Fi for calls
* **Keyboard shortcuts:** `Cmd + E` (Search), `Cmd + Shift + M` (Mute), `Cmd + Shift + O` (Toggle camera)
